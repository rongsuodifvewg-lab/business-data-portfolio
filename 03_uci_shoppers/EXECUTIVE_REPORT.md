# 项目三：电商转化漏斗与用户行为分析

## 决策问题

哪些用户场景和站内行为与购买转化最相关？产品、运营和再营销团队应该先优化什么？

## 关键结果

- 全样本为 12,330 次会话；新访客转化率约 **24.9%**，回访访客约 **13.9%**。
- 月度转化率差异明显：11 月约 **25.4%**，而 2 月仅约 **1.6%**；这说明季节性或流量结构是重要经营变量。
- 买家平均浏览产品页约 **48.2** 页、产品页停留约 **1,876 秒**；非买家分别约 **28.7** 页和 **1,070 秒**。
- 买家平均 PageValues 约 **27.3**，非买家约 **2.0**；退出率和跳出率也明显更低。
- 逻辑回归在留出测试集上的 ROC-AUC 约 **0.897**，Average Precision 约 **0.620**。这是转化排序能力，不是因果效果。

## 商业建议

1. 将 PageValues、产品页深度和退出率作为高意向识别信号，建立再营销或站内推荐优先级。
2. 11 月等高意向月份重点做流量承接和库存/促销准备，2 月等低转化月份先检查流量质量与落地页匹配度。
3. 新访客转化率高于回访访客，不能简单把全部回访用户当作高价值；应进一步按来源、历史行为和页面深度分层。
4. 通过 A/B 测试验证页面改版或再营销策略是否真的提升转化；本项目本身没有处理组，不能直接声称任何行为导致购买。
